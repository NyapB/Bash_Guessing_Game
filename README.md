# 🏷 guessing-game

A guessing game built with batch

## 📌 Problem Statement

using this project to learn and practice bash programming

## 🎯 Project Goals

The project's goal is to allow users to input numbers over and over until they guess the random number given by the program correctly.

## 🛠 Tech Stack

bash

## ⚙ Installation & Setup

clone the repository

```bash
git clone https://github.com/NyapB/Bash_Guessing_Game.git

- cd Bash_Guessing_Game
- give permission using chmod +x guessing-game.sh
- run with ./guessing-game.sh
```

## 🧠 Challenges Faced

Handling limit for random selection function
using the count function to deternine the number of times the user tried before getting it right.
